# Security policy

Kidfin is a convenience barrier for a cooperative household, not tamper-proof parental control
(see the threat model in the README). Reports about bypasses that need developer access, a
different app or uninstalling are therefore expected limitations.

Please report anything else privately, for example leaked credentials or tokens, a way to start
playback without grown-up approval, or a way to extend or skip a session limit.

Use GitHub's "Report a vulnerability" (private security advisory) on this repository. Do not open
a public issue for security problems. Include the app version, device, and steps to reproduce.
Never include real passwords or tokens.

This is a volunteer project: expect an acknowledgement within about a week.
